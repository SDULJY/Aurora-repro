# Phase 0 观测验证试点

## 设置

- 起报：`2022-01-02T00:00:00Z`
- 时效：+6h / +12h / +18h / +24h（4 步 rollout）
- 模型：HRES T0 初始场 + `aurora-0.25-finetuned.ckpt`（LoRA）
- 观测：NOAA ISD-Lite 2022 地面站 + IGRA2 2022 探空
- 参考：ERA5 0.25°（WB2）与 persistence（HRES T0 初始场持续）
- 匹配：最近 0.25° 格点；ISD 取整点；IGRA2 取 00/12 UTC

本次只验证**数据解析、台站匹配、指标计算**是否可靠，样本不代表全球；Phase 2 再扩展到 16 个 case 和更平衡的台站集。

## 主要发现

1. **管线跑通**：ISD/IGRA2 下载、解析、时间/空间匹配、海拔订正、指标和图都能端到端运行。
2. **地面变量量级合理**：2t 对观测 RMSE 约 2.3–2.9 K，msl 约 0.94–1.09 hPa，10u 约 1.7–2.0 m/s；都明显优于 persistence。
3. **2t 海拔订正效果混合**：+24h 从 2.325 降到 2.236 K，但 +12/+18h 略变差，且引入正偏差；Phase 2 需要对所有方法使用同一订正并分层。
4. **探空量级合理**：t850 在 +12h 约 1.07 K、+24h 约 0.48 K；z500 在 +12h 约 7.7 m、+24h 约 20 m；Aurora 与 ERA5 的误差量级接近，剩余偏差主要来自观测代表性/探空采样，而不是模式坐标错位。
5. **发现并修复一个关键 bug**：IGRA2 台站表的负纬度/负经度字段被截掉符号，导致 Learmonth/Perth 等站被匹配到北半球；修正后 t850/z500 偏差从 ~5–7 K / ~40 m 降到上表量级。

## 问题与 Phase 1 建议

- **台站样本不平衡**：当前 ISD/IGRA2 选站偏海岛/边远站；Phase 1 应按大洲/纬度带配额选站，并报告每个区域的站数。
- **2t 订正**：Phase 1 统一用模式地形对 Aurora/ERA5/persistence 做同一 lapse-rate 订正，并保留 raw/adj 两套指标；复杂地形单独分层。
- **时间匹配**：Phase 1 增加 ISD ±30 min 窗口和双线性空间插值敏感性。
- **QC**：Phase 1 引入 ISD 完整版 QC 标志，剔除异常温度/气压/风速；IGRA2 增加层次完整性检查。
- **统计**：Phase 1 增加按 case/站分块 bootstrap 95% CI、ACC（ERA5 气候态插值到台站）和区域/季节分层。
- **数据管线**：把现在的 `pilot_obs.py` 拆成 `obs_sources.py` / `fetch_obs.py`，增加解析单元测试和缓存；IGRA2 解析结果缓存为 npz，避免每次扫描 20 年全序列。
- **网络**：HRES T0 已改为 HTTP zarr + 本地缓存（`cache/hres_ic_*.npz`），避免 gcsfs 大 chunk 卡死；`sources.py` 的 WB2/HRES/气候态均已切换。
