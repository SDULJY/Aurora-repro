# Phase 2/3：观测验证结果（2022 四季节，16 起报 × 10 天）

## 设置

- 起报：2022-01-02/16、04-01/15、07-01/15、10-01/15，00/12 UTC，共 16 个 case
- 时效：+6h 至 +240h，每 6h，共 40 个
- 模型：HRES T0 初始场 + `aurora-0.25-finetuned.ckpt`（LoRA）
- 观测：ISD-Lite 2022（2t/msl/10u）+ IGRA2 2022（t850/z500）
- 基线：persistence（HRES T0 持续）、ERA5-at-station（再分析参考，不是预报）
- 匹配：最近 0.25° 格点；ISD 取 ±30 min 内最近整点；IGRA2 取 00/12 UTC
- 2t 海拔订正：`T_adj = T + 0.0065*(z_model - z_station)`，同时保留 raw/adj

## 台站覆盖

| 来源 | 数量 | 说明 |
|---|---|---|
| ISD-Lite | 181 | 美国 120，非美国 61；中纬 141、热带 34、极区 6；10u 覆盖 181 |
| IGRA2 | 200 | 中纬 88、极区 56、热带 56 |

**限制**：2022 年 ISD-Lite 通过覆盖率筛选的非美国站很少，地面结果仍偏美国；不要把 181 站当作全球面积平均。报告中的 US/non-US 分层可帮助判断偏差。

## 主要发现

1. **Aurora 明显优于 persistence**：2t +240h 3.92 K vs 6.71 K；msl 5.13 vs 8.64 hPa；t850 3.73 vs 5.68 K；z500 82.4 vs 124.5 m。观测验证确认了模型有真实预报技巧，而不只是拟合 ERA5。
2. **ERA5-at-station 的 RMSE 不随 lead 增长**，因为它是在验证时刻的再分析，不是预报；它只能作为“再分析相对观测”的参考，不能当作预报基线。
3. **2t 海拔订正效果有限**：+24h 2.241→2.236 K，+120h 2.630→2.621 K，但 +240h 3.917→3.980 K 反而略差；订正引入正偏差。后续需要按 |Δz| 分层或使用更合理的地形订正。
4. **变量差异**：msl/10u 在 +24h 与 ERA5 接近；t850/z500 在 +24h 与 ERA5 接近，但 +120/+240h 误差增长明显，说明长时效的主要误差来自模式预报而不是观测匹配。
5. **区域分层（2t Aurora）**：+24h 热带 1.40 K、中纬 2.35 K、极区 3.07 K；+240h 热带 2.05 K、中纬 4.16 K、极区 5.40 K。非美国站 +240h 3.04 K，美国站 4.28 K；区域/台站差异显著。

## 限制

- ISD 站偏美国；非美国站仅 61 个，地面统计不能代表全球陆地。
- 观测是点尺度，模式是 0.25° 格点面积平均；2t 在复杂地形、msl 在高原、10u 在沿海/城市站都有代表性误差。
- 本次未计算 ACC（需要额外下载 1.5° 气候态）和 bootstrap 置信区间；summary 中的 `rmse_case_std` 是跨 case 标准差。
- 只验证 2022 年 16 个 case；不是多年气候统计。
