# 观测验证协议（Phase 0 草案）

本文定义 Aurora 复现项目的观测验证口径。Phase 0 只用 1 个 case 做试点，验证数据解析、台站匹配和指标计算是否可靠；Phase 2/3 再扩展到 16 个 case 和全量台站。

## 1. 验证目标

回答两个不同的问题：

1. **相对再分析（ERA5）的技巧**：当前 `results/paper_2022_4season_10d` 已经回答。ERA5 空间完整、动力一致，但不是独立观测。
2. **相对真实观测的技巧**：本文定义的观测验证。观测是点尺度、非连续、含仪器/代表性误差的；结果不应与 ERA5 口径直接比较。

因此，同一批台站上要同时报告：

- `aurora vs obs`：真实观测误差；
- `era5 vs obs`：再分析在该站的代表性/误差；
- `aurora vs era5`（同一格点）：模式与再分析的差异；
- `persistence vs obs`：初始场持续预报基线。

`aurora vs obs` 与 `era5 vs obs` 的差距，主要反映观测代表性、再分析误差和模式误差，不应简单归因于模型技巧。

## 2. 变量与数据源

### 2.1 地面站（ISD-Lite）

- 数据源：NOAA ISD-Lite 2022 年，按台站年文件；
- 变量：
  - `2t`：气温，K；
  - `msl`：海平面气压，hPa；
  - `10u`：10 m 纬向风，m/s（由风向/风速转换）。
- 原始单位：气温 0.1°C、SLP 0.1 hPa、风速 0.1 m/s；缺测 `-9999`。
- 风向转换：`u = -speed * sin(dir)`，`v = -speed * cos(dir)`，`dir` 为气象风向（风的来向）。

### 2.2 探空（IGRA2）

- 数据源：NOAA IGRA2 `data-por` 2022 年；
- 变量：
  - `t850`：850 hPa 温度，K；
  - `z500`：500 hPa 位势高度，m。
- 原始单位：气压 Pa、位势高度 m、温度 0.1°C、风速 0.1 m/s；缺测 `-9999`。
- 只使用 00/12 UTC 的探空时次；与模式 6h 时效对齐。

### 2.3 模式输出

Aurora 0.25° 输出：

- 地面：`2t`（K）、`msl`（Pa，评估时转 hPa）、`10u`（m/s）、`10v`；
- 高空：13 层 `t/u/v/q/z`；`z` 为位势（m²/s²），评估时 `/g` 转位势高度（m）；
- 静态场：`z`（地形位势，`/g` 转 m）、`lsm`、`slt`；
- **没有地面气压、降水、辐射和地表通量**，因此不能严格闭合质量/能量/水守恒。

## 3. 台站筛选

### 3.1 ISD

从 `isd-history.csv` 筛选：

- `BEGIN <= 2022-01-01` 且 `END >= 2022-12-31`；
- 经纬度有效，排除 `(0, 0)` 和 `ELEV <= -999`；
- 排除 `WBAN = 99999` 的站（数据覆盖通常较差）；
- 按 30° 纬度 × 60° 经度分箱，轮转抽样，避免欧洲/北美过度集中；
- 下载候选站文件后，要求：
  - 试点 4 个时次中至少 2 个有 `2t` 和 `msl`；
  - 2022 年 00/06/12/18 UTC 至少 200 个有效 `2t` 和 `msl`；
  - `10u` 不强制，但优先选择有风的站。

Phase 0 目标：60 个站；若通过筛选的站不足，按实际数量报告。

### 3.2 IGRA2

- `LAST >= 2022` 且 `FIRST <= 2022`，`COUNT > 100`；
- 按 30°×60° 分箱，优先全球分布；
- Phase 0 目标：10 个站；要求至少一个目标时次有 `t850` 或 `z500`，优先两个时次都有的站。

## 4. 时间与空间匹配

- 模式网格：0.25°，720×1440；纬度 90…-89.75，经度 0…359.75。
- 空间匹配：Phase 0 用**最近格点**；Phase 2 增加双线性插值做敏感性对比。
- 时间匹配：
  - ISD：取与模式时效完全相同的整点（06/12/18/24 UTC）；不做时间插值；
  - IGRA2：00/12 UTC，对应 +12h / +24h 等时效。
- 经度：台站经度 `lon % 360` 后再找最近格点，避免 0/360 断裂。

### 4.1 海拔订正

模式格点地形 `z_model = static_z / g`；台站海拔 `z_station` 来自 ISD/IGRA2 元数据。

- `2t`：`T_adj = T_model + 0.0065 * (z_model - z_station)`（K）；
  - 同时报告未订正值；
  - `msl` 已归算到海平面，不做海拔订正；
  - `10u` 不做高度订正。
- 代表性：`|z_model - z_station|` 作为分层变量；复杂地形站单独报告。

Phase 0 的 `aurora_adj` 只对 Aurora 做订正，ERA5/persistence 保持原始格点值；Phase 2 会对所有方法使用同一订正做敏感性分析。

## 5. 指标

对每个 `variable × lead × method`：

- `n`：有效配对样本数；
- `bias = mean(pred - obs)`；
- `MAE = mean(|pred - obs|)`；
- `RMSE = sqrt(mean((pred - obs)^2))`；
- `corr = corr(pred, obs)`（n≥3 且方差非零）。

说明：

- 台站指标不做面积加权；台站稀疏，不能直接解释为全球面积平均；
- Phase 2 增加按 case/站分块的 bootstrap 95% CI；
- Phase 2 增加 ACC：用 ERA5 1990–2019 气候态插值到台站，异常相关系数；
- Phase 0 不计算 ACC，避免把气候态误差混入试点结论。

## 6. 基线与对照

- `aurora`：Aurora 直接输出；
- `aurora_adj`：2t 海拔订正后的 Aurora（仅 2t）；
- `era5`：ERA5 在最近格点的值（参考，不是真值）；
- `persistence`：HRES T0 初始场在最近格点的值，持续到所有时效；
- Phase 2 增加 `climatology` 基线。

## 7. 分层（Phase 2 起）

- lead time；
- 季节；
- 纬度带：热带（|lat|<23.5°）、中纬（23.5°–60°）、高纬（>60°）；
- 地形：`|z_model - z_station|` 分箱；
- 区域/国家；
- 台站类型（ICAO 机场站 vs 其他）。

## 8. 已知限制

1. **观测不是“真值”**：ISD/IGRA2 是点尺度观测，含仪器误差、代表性误差和 QC 问题；模式格点是面积平均。
2. **样本不代表全球**：台站分布不均，探空站稀疏；结论应带台站数和区域分层。
3. **2t 海拔订正粗糙**：固定 6.5 K/km 只是近似；复杂地形站应单独看。
4. **msl 归算误差**：ISD 的 SLP 在高原/复杂地形有归算误差；不能与模式 msl 完全等价。
5. **10u 代表性**：风速受观测高度、下垫面、仪器影响；模式 10u 是格点平均。
6. **时间匹配**：ISD 只取整点，可能错过模式时效附近的变化；Phase 2 可加 ±30 min 窗口敏感性。
7. **没有地面气压/通量/降水**：物理部分只能做约束、平衡、谱和漂移诊断，不能声称严格守恒。
